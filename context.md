## What this repo does
This project is a single-page browser game where players flip cards to find matching pairs. It is built with plain HTML, CSS, and JavaScript and runs directly in the browser without any external dependencies.

### Core gameplay
- Players reveal two cards at a time
- Matching cards stay face-up
- Non-matching cards flip back after a short delay
- The game ends when all pairs are matched
- Players can choose between 4x4 and 6x6 board sizes

### Included features
- Responsive layout for desktop and mobile screens
- Move counter
- Timer
- Star rating based on performance
- Best score tracking using localStorage
- Keyboard accessibility using Tab + Enter/Space
- Win modal and replay flow
