# Memory Game

A responsive and accessible Memory (Concentration) card game built with HTML, CSS, and JavaScript. This project was created as a simple browser-game practice project and includes a dark mode toggle for better low-light usability.

## Features

- 4x4 and 6x6 grid options
- Smooth card flip animations
- Timer and moves counter
- Star rating system
- Local storage for best scores
- Light and dark theme toggle
- Keyboard controls for accessibility
- Responsive design for all devices
- No external dependencies

## How to Play

1. Open `memory-game.html` in a web browser.
2. Click or use keyboard controls (Tab + Enter/Space) to flip cards.
3. Match all pairs to complete the game.
4. Try to finish with as few moves as possible.
5. Switch between 4x4 and 6x6 grids using the buttons.
6. Use the theme toggle to switch between light and dark mode.

## Project Overview

This repository contains a single-page memory game that runs directly in the browser. It demonstrates front-end DOM manipulation, CSS styling, game state handling, and localStorage-based score tracking in pure JavaScript.

## Technical Details

- Pure HTML, CSS, and JavaScript implementation
- No external libraries or dependencies
- Fully responsive design using CSS Grid
- Accessible with ARIA attributes and keyboard controls
- Dark mode support with persistent theme preference
- Local storage for persistent high scores

## Run the Game

Open the file directly in a browser, or run a local web server:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000/memory-game.html
```
